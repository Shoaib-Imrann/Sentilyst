# Sentilyst

Sentilyst is an M&A (Mergers & Acquisitions) Analysis Platform that provides sentiment analysis for business deals and market trends.

## Features

- **Sentiment Analysis**: Analyze text data from multiple sources to determine positive and negative sentiment
- **Risk Assessment**: Calculate risk levels based on sentiment analysis
- **Multi-Source Data**: Scrape and analyze data from Reddit and Google News
- **User Authentication**: Email/password and Google OAuth login
- **Saved Analysis**: Store and retrieve previous analyses

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Recharts for data visualization

### Backend
- FastAPI
- Supabase for database
